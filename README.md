# Digital Operations Analytics Dashboard

A Python and SQL project for exploring IT service performance, incident trends and operational KPIs. It combines Pandas data preparation, SQLite queries and a Streamlit dashboard.

**Data:** The project uses synthetic data from eight fictional business applications. It is not connected to live services or employer systems.

## What it does

- **Overview:** Summarises request volume, error rates and incident counts.
- **Service health:** Compares daily latency, request volume and error rates for individual services.
- **Analytics:** Filters incident records by application and priority, with CSV export.
- **SQL explorer:** Runs read-only SQLite queries, including filtering, aggregation and joins.

## Findings

A review of the sample dataset highlighted two services for further investigation:

| Service | Daily error rate (3 Nov 2026) | Sample threshold |
|---|---:|---:|
| Payroll & HR Portal | 2.45% | 1.00% |
| Engineering PLM | 1.74% | 1.50% |

The incident table includes three simulated P2 Payroll incidents. Their affected-user estimates total **12,801 across incidents**; this is not a count of unique users. The daily measurements and incident records were generated separately, so this comparison does not establish the cause of any incident.

## Run locally

Python 3.10 or later is recommended. In a terminal opened in this project directory, run:

```cmd
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Streamlit normally opens at `http://localhost:8501`. Press `Ctrl+C` in the terminal to stop the app.

On subsequent runs, activate `.venv` and run `python -m streamlit run app.py`.

## Methods

- **Data preparation:** Read CSV files using Pandas, remove duplicates, convert data types and validate required fields.
- **Analysis:** Group records by service, calculate totals and request-weighted error rates, and compare metrics with defined service thresholds.
- **SQL:** Use `SELECT`, `WHERE`, `GROUP BY`, `ORDER BY` and `JOIN` to inspect incidents and service data.
- **Visualisation:** Display KPIs, charts and filtered incident tables with Streamlit and Plotly.

## Validation

Run the included checks:

```cmd
python -m unittest discover -s tests -v
```

Regenerate the daily records using a fixed random seed:

```cmd
python generate_sample_data.py
```

The incident dataset is not regenerated by that command.

## Data limitations

All records are synthetic. The 15 incident rows include three adapted from a separate synthetic Payroll incident export, while the other 12 are additional sample records. The daily service measurements were generated independently.

Daily error rates are averages, not incident peaks. Estimated affected-user counts may overlap between incidents. The dashboard supports exploratory analysis, not real-time monitoring or confirmed root-cause diagnosis.
