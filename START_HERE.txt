DIGITAL OPERATIONS ANALYTICS - QUICK START

1. Open a terminal in this project folder.
2. Run these commands on Windows:

   python -m venv .venv
   .venv\Scripts\activate
   python -m pip install -r requirements.txt
   python -m streamlit run app.py

3. Open http://localhost:8501 if the browser does not open automatically.
4. For a sample investigation, open Analytics, filter Payroll & HR Portal,
   then use the Payroll query in SQL Explorer.
5. See CASE_STUDY.md for the results and methodology.

Run tests:
   python -m unittest discover -s tests -v

All data in this repository is synthetic. No live services are connected.
